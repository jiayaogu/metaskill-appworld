# Intermediate one-third sample

This directory contains complete AppWorld scenario manifests for 10 train,
19 test-normal, and 46 test-challenge families, plus the distribution audit.
The [method and results](../../intermediate_1of3_sampling.md) explain the
selection and its limits. Regenerate the files with
[`sample_intermediate_1of3.py`](../../code/sample_intermediate_1of3.py).
